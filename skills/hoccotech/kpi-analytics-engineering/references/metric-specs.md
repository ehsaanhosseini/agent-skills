Common definitions to settle explicitly:
- Occupancy = occupied room-nights / available room-nights (exclude out-of-order rooms; state it).
- RevPAR = room revenue / available room-nights; ADR = room revenue / sold room-nights.
- Conversion = completed goal / eligible sessions or leads; state the window.
- Utilization = booked or billable time / available time.
- No-show rate = no-shows / confirmed appointments or reservations.
- Retention and churn: cohort by first-activity period; define "active".
- Revenue: gross vs net, tax, refunds, currency and conversion date.
Distinguish leading from lagging metrics, and add one guardrail per target to prevent gaming.
