# Optional knowledge representations

Machine-readable exports can serve a specific documented integration, but they are not a prerequisite for Google AI features or an established ranking signal. Verify any proposed format's current specification and actual consumer support before choosing it. Prefer existing public HTML, feeds or documented APIs when sufficient.

For a requested llms.txt, Markdown, OKF or similar export, define scope, ownership, canonical URLs, revision/freshness, link integrity and update/deletion behavior. Export only already-authorized public content; exclude internal docs, secrets, unpublished plans, user data and private product details.

Test parity with public pages and stale/deleted content. Keep experiments reversible, and do not install generators or publish dumps automatically. If no consumer need or measurable test exists, recommend deferring the extra maintained surface.
