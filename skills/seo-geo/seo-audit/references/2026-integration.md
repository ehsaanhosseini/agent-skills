# Integration review: local search and title evidence

Separate technical diagnosis, local entity consistency and content relevance. For local businesses verify real eligibility, approved identity/contact information, useful service pages and honest reviews; avoid virtual locations and doorway pages. For title changes use page intent and actual content, then observe Search Console outcomes with seasonality caveats. Distinguish ranking fluctuations from tracking/site changes. Official search guidance governs and no finding guarantees ranking gains.

## Verification
