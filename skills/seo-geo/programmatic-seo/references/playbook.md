# Programmatic Seo playbook

## Establish the decision

User search intent, unique data, page family, source rights, inventory quality and indexing policy.

Use supplied, authorized evidence first. Label missing inputs and choose a reversible recommendation if uncertainty remains; do not invent a baseline, market statistic or guaranteed improvement.

## Method and tradeoffs

Validate that each page answers a distinct useful need with reliable information before templating. Define minimum data quality, original value, canonical rules and duplicate handling. Pilot a small representative set; inspect rendering, internal linking, empty inventory and indexability before scaling. Keep unsupported combinations unpublished or appropriately excluded under the approved policy.

## Worked example

A hospitality directory should publish useful property pages with real availability context, not thousands of interchangeable city-keyword pages.

## Verify and diagnose

Check data provenance, uniqueness, semantic HTML, crawlable links, canonicals, sitemap inclusion and current Google spam guidance. Monitor indexed useful pages and qualified outcomes rather than page count.

If evidence is incomplete, state exactly which conclusion cannot be supported and what observation would resolve it. Check for instrumentation faults, cohort selection, seasonality and delayed outcomes before attributing a change to an intervention. Keep unrelated workflows unloaded.

## Deliverable

Provide the artifact requested, its evidence and assumptions, a prioritized recommendation with the material tradeoff, and observable acceptance criteria. Include a staged rollout or recovery plan only when implementation risk requires it. Do not label a proposal as an executed result.
