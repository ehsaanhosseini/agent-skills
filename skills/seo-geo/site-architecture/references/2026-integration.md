# Integration review: platform-aware migration

Before changing URL families, inspect actual platform routing, canonical rules, locales and current indexed URLs. Create a one-to-one old/new URL map where possible, preserve meaningful navigation and internal links, and stage redirect/canonical/sitemap changes together. Validate representative redirects, loops, empty categories, parameter variants and hreflang relationships locally before release. Preserve approved indexing policy and production authorization.

## Verification

Work from authorized inputs; record observations, assumptions, unverified evidence and the actual checks performed. Compare the proposed outcome with the baseline and preserve unrelated approved behavior. Do not label recommendations or metadata validation as observed product results.
