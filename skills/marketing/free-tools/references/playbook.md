# Free Tools playbook

## Establish the decision

Audience task, input availability, expected output value, distribution channel, maintenance budget and data sensitivity.

Use supplied, authorized evidence first. Label missing inputs and choose a reversible recommendation if uncertainty remains; do not invent a baseline, market statistic or guaranteed improvement.

## Method and tradeoffs

Choose a tool that solves a narrow real problem and demonstrates the paid product's value. Decide whether ungated output is sufficient before adding lead capture. Specify input validation, transparent formulas, accessibility, abuse controls and a useful failure state. Estimate ongoing support and compute cost before choosing AI or external APIs.

## Worked example

An occupancy calculator should state available-room-night and sold-room-night definitions, accept valid date ranges and avoid asking for guest identities.

## Verify and diagnose

Validate calculations against worked examples, boundary inputs, mobile use and export behavior. Measure completed useful tasks, qualified product interest and cost per completion.

If evidence is incomplete, state exactly which conclusion cannot be supported and what observation would resolve it. Check for instrumentation faults, cohort selection, seasonality and delayed outcomes before attributing a change to an intervention. Keep unrelated workflows unloaded.

## Deliverable

Provide the artifact requested, its evidence and assumptions, a prioritized recommendation with the material tradeoff, and observable acceptance criteria. Include a staged rollout or recovery plan only when implementation risk requires it. Do not label a proposal as an executed result.
