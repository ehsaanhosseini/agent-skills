# Optional initiative menu

Adapted from Marketing Skills marketing-ideas at `88c79f6528a9347420e57ceb1fff9a60de651768` (MIT). This is a selection aid, not a checklist to execute. Choose by bottleneck, audience fit, economics, capacity and evidence.

| Constraint | Candidate mechanisms | Before investing |
|---|---|---|
| Unclear audience/value | Customer interviews, segment research, positioning tests | Separate observed jobs from assumed demand |
| Weak qualified discovery | Search content, useful tools, relevant directories, earned PR, partnerships | Verify actual audience and useful original value |
| Paid demand inefficiency | Intent segmentation, negative terms, creative hypotheses, landing alignment | Verify qualified conversion signal and capped economics |
| Registration drop-off | Progressive profiling, clearer terms, accessible validation | Preserve auth and required consent |
| Slow first value | Minimum path to value, meaningful empty states, contextual help | Validate activation against retained outcomes |
| Poor commerce conversion | Product data, trust/fulfillment clarity, cart recovery, checkout diagnosis | Verify inventory/payment failures and refund/margin guardrails |
| Low retention | Service recovery, relevant education, pause options, provider-supported dunning | Diagnose reasons/cohorts; keep cancellation easy |
| Weak advocacy | Honest review requests, customer referrals, creator and partner programs | Check incentive economics, consent and platform rules |
| Sales handoff leakage | Lifecycle criteria, SLA, routing fallback, demo/battlecards | Agree ownership and objective stage definitions |
| Unclear monetization | Value-metric research, packaging, bounded new-customer price tests | Model cost, demand uncertainty and contract constraints |

For a selected initiative use its specialist skill, not the full library. Avoid spam, fabricated scarcity/reviews, covert collection and ranking guarantees even if a historic idea suggests them. State the hypothesis, smallest useful test, owner, required approvals, outcome and stop rule.
