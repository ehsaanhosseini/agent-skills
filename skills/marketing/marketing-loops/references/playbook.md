# Marketing Loops playbook

## Establish the decision

Outcome, data source, meaningful-change threshold, cadence, state location, allowed actions, cost cap and owner.

Use supplied, authorized evidence first. Label missing inputs and choose a reversible recommendation if uncertainty remains; do not invent a baseline, market statistic or guaranteed improvement.

## Method and tradeoffs

Specify check cadence separately from acts-when condition. Define read inputs, verification, dedupe key, cooldown, output, error halt and kill switch. Start with one useful loop; design composition only for a demonstrated need. Use a supported scheduler only when creation is explicitly requested and authorized; describe a manual cadence otherwise.

## Worked example

A weekly ad-efficiency review checks qualified conversion lag and tracking health, then stages recommendations only when an agreed threshold is crossed. Keep quiet while unchanged; never shift spend on its own.

## Verify and diagnose

Dry-run on unchanged, changed, duplicate and unavailable-data fixtures. Verify no duplicate notifications/actions, no actions on stale data, capped resource use and explicit stop/error behavior.

If evidence is incomplete, state exactly which conclusion cannot be supported and what observation would resolve it. Check for instrumentation faults, cohort selection, seasonality and delayed outcomes before attributing a change to an intervention. Keep unrelated workflows unloaded.

## Deliverable

Provide the artifact requested, its evidence and assumptions, a prioritized recommendation with the material tradeoff, and observable acceptance criteria. Include a staged rollout or recovery plan only when implementation risk requires it. Do not label a proposal as an executed result.
