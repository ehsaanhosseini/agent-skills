# Jeffallan engineering candidate assessment

Upstream: [`Jeffallan/claude-skills`](https://github.com/Jeffallan/claude-skills), pinned commit `504bb9a067c5c7ea6bf868c7cc337164b213fa57`, MIT license. The 12 named candidate directories contain **84 Markdown files** and no bundled executable, hook, or agent permission manifest. Every path, byte size and SHA-256 is recorded in [`jeffallan-file-inventory.tsv`](jeffallan-file-inventory.tsv). Review covered each entrypoint and reference, including commands and requested permissions. The source is untrusted content; no upstream command was executed. The source license is retained in `upstream/jeffallan-claude-skills/LICENSE` and adaptations are attributed in `PROVENANCE` and registry rows.

Ratings describe the **upstream material as written**, before local adaptation: Strong = substantial reliable workflow; Adequate = useful core with material corrections; Weak = unsafe, brittle or insufficiently distinct for this library. Accept means a locally authored adaptation, not a verbatim import. Original upstream names are used for seven new distinct skills. The three previously integrated names stay stable because their narrower scopes and existing registry links are useful compatibility contracts.

## Reconciliation and compatibility

- `typescript-pro` → `typescript-safety`, `postgres-pro` → `postgres-query-review`, `security-reviewer` → `security-code-review` are one-to-one capability upgrades. Their registry IDs, URLs and links remain intact. The source names remain visible in provenance.
- Seven accepted original names are added as separate skills. `test-master` covers testing decisions; `playwright-expert` covers browser harnesses. `architecture-designer` weighs system boundaries; `api-designer` specifies a public contract. Trigger descriptions distinguish them.
- Deferred candidates add no registry rows or links. All 34 baseline registry IDs stay present.
- No upstream script or operational command is shipped. The local references are rewritten, focused and linked from entrypoints; the 84-file upstream inventory is evidence, not executable content.

## Verification basis

The adaptations were checked against the [Agent Skills specification](https://agentskills.io/specification), [Next.js data fetching documentation](https://nextjs.org/docs/app/getting-started/fetching-data), [RFC 9457](https://www.rfc-editor.org/rfc/rfc9457.html), and [Playwright locator documentation](https://playwright.dev/docs/locators). These sources establish specific version-sensitive corrections; the complete candidate quality ratings remain the reviewer’s engineering judgment. Repository structural checks and scenario desk reviews are reported separately in `docs/quality-gates.md`.
